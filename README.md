# Awesome-HAM


## 天线
[业余无线电可视化](https://ham.charlesify.com/) - 业余无线电天线辐射图与物理原理的交互式 3D 可视化平台。

## 日志
[LoTW](https://lotw.arrl.org/lotwuser/default) - 由美国业余无线电协会（ARRL）运营的官方在线日志数据库，为全球业余无线电爱好者提供权威、自动化的通联确认（QSL）服务

## 社区
[QRZ](https://www.qrz.com/) - 全球业余无线电（HAM）领域最核心、最权威的在线社区和呼号查询数据库

[HamCQ](https://forum.hamcq.cn/) - 中文社区

## 设备

## 网页应用
[K5Web](https://k5.vicicode.cn/#/chirp/base) - 泉盛 K5/K6 在线写频及刷固件。

[快点摩尔斯电码](https://cw.quickso.cn/) - CW 在线练习网站

[Web Morse Runner](https://fritzsche.github.io/WebMorseRunner/) - 摩尔斯电码练习器

[Heavens-Above](https://www.heavens-above.com/) - 提供精确卫星及天体过境预报

[Satellites](https://satellites.browxy.com/pass) - 卫星过境预测

[APRS地图（.tv）](https://aprs.tv/) - APRS 实时地图网站（国内版）

[APRS地图（.fi）](https://aprs.fi/) - APRS 实时地图网站（国际版）

[PSK reporter](https://pskreporter.info/) - 全球性信号报告网络和可视化平台。核心功能就是一张“全球实时信号地图”。你可以把它理解成一个由全球爱好者共同维护的“信号监测系统”。[PSK 地图](https://pskreporter.info/pskmap.html)

[DXlook](https://www.qsl.net/ak6fp/dxlook-hamclock-alternative/) - 免费的、基于网页的业余无线电传播分析与可视化平台。可以把它看作一个功能强大的“传播洞察仪表盘”，它能帮你实时回答：“我的信号能被谁听到？”以及“从我的位置看，现在的传播到底怎么样？” [DXlook 地图](https://dxlook.com/)

## 软件
[Morse Runner Community Edition](https://github.com/w7sst/MorseRunner) - 训练业余无线电（Ham Radio）操作员抄收摩尔斯电码（CW） 和应对堆叠（Pileup） 信号能力的模拟训练软件。

[Morse Runner](https://github.com/net3pang/MorseRunner-Cross-Platform) - Morse Runner — 跨平台版 (Cross-Platform)
